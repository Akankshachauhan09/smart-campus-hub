Web Development Notes

Complete beginner-friendly Web Development study notes

1. What is Web Development?

Web development is the process of creating and maintaining websites and web applications.

2. Types of Web Development

  • Frontend Development
  • Backend Development
  • Full Stack Development

3. Frontend Development

Frontend is the part of a website that users can see and interact with.

  • HTML
  • CSS
  • JavaScript
  • Bootstrap
  • React

4. Backend Development

Backend handles server-side logic, databases, authentication and APIs.

  • Node.js
  • Express.js
  • PHP
  • Python
  • Java

5. Full Stack Development

Full Stack Development involves both frontend and backend development.

Example: MERN Stack

  • MongoDB
  • Express.js
  • React
  • Node.js

6. Website vs Web Application

A website mainly provides information, while a web application allows users to perform interactive tasks.

7. Client and Server

Client: The user's browser or device.

Server: A computer/system that processes requests and sends responses.

8. HTTP

HTTP stands for HyperText Transfer Protocol. It is used for communication between client and server.

9. API

API stands for Application Programming Interface. It allows different software systems to communicate with each other.

10. Domain and Hosting

Domain: The address of a website.

Hosting: A service that stores website files and makes them available on the internet.

  4. Testing
  5. Deployment
  6. Maintenance

12. Important Questions

Q1. What is web development?

It is the process of creating and maintaining websites and web applications.

Q2. What is frontend?

The user-facing part of a website.

Q3. What is backend?

The server-side part of a web application.

Q4. What is full stack development?

Development involving both frontend and backend.

Q5. What is an API?

An interface that allows software systems to communicate.
