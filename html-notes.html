HTML Notes

Complete beginner-friendly HTML study notes

1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML is not a programming language. It is a markup language.

2. Basic HTML Structure

<!DOCTYPE html>

<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>
    <p>Welcome to my website.</p>

</body>

</html>

3. HTML Tags

Some important HTML tags are:

  • <h1> - Heading
  • <p> - Paragraph
  • <a> - Link
  • <img> - Image
  • <br> - Line Break
  • <hr> - Horizontal Line
  • <div> - Container
  • <span> - Inline Container

4. Headings

HTML provides six levels of headings: 

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

5. Text Formatting

<b>Bold Text</b>

<i>Italic Text</i>

<u>Underline Text</u>

<strong>Important Text</strong>

<em>Emphasized Text</em>

6. HTML Links

The <a> tag is used to create hyperlinks. 

<a href="https://example.com">
    Visit Website
</a>

7. Images

The <img> tag is used to display an image. 

<img src="image.jpg"
     alt="College Campus"
     width="300">

src = Image location
alt = Alternative text

8. HTML Lists

Unordered List
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Ordered List
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

9. HTML Tables

<table border="1">

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Akanksha</td>
        <td>Computer Science</td>
    </tr>

</table>

10. HTML Forms

Forms are used to collect information from users. 

<form>

    <label>Name:</label>
    <input type="text">

    <label>Email:</label>
    <input type="email">

    <input type="submit"
           value="Register">

</form>

12. Semantic HTML

Semantic tags clearly describe their meaning and purpose.

  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <aside>
  • <footer>

13. Audio & Video

<audio controls>
    <source src="music.mp3">
</audio>


<video controls width="400">
    <source src="video.mp4">
</video>

14. HTML Comments

Comments are not displayed on the webpage. 

<!-- This is an HTML comment -->

15. Important Questions

Q1. What is HTML?

HTML is a markup language used to structure web pages.

Q2. Is HTML a programming language?

No. HTML is a markup language.

Q3. What is the use of the <a> tag?

It is used to create hyperlinks.

Q4. What is the use of the <img> tag?

It is used to display images.

Q5. What is an HTML attribute?

An attribute provides additional information about an HTML element.
