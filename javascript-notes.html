JavaScript Notes

Complete beginner-friendly JavaScript study notes

1. What is JavaScript?

JavaScript is a programming language used to make webpages interactive and dynamic.

HTML creates structure, CSS provides design and JavaScript adds functionality.

2. Adding JavaScript to HTML

<script>

    alert("Hello World");

</script>

3. Variables

let name = "Akanksha";

const age = 20;

var city = "Azamgarh";

let and const are commonly used in modern JavaScript.

4. Data Types

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • Object
  • Array

5. Operators

+     Addition
-     Subtraction
*     Multiplication
/     Division
%     Modulus
==    Equal
===   Strict Equal
!=    Not Equal

6. Conditional Statements

let age = 18;

if (age >= 18) {

    console.log("Eligible");

} else {

    console.log("Not Eligible");

}

7. Loops

for (let i = 1; i <= 5; i++) {

    console.log(i);

}

8. Functions

function greet() {

    console.log("Hello Student");

}

greet();

9. Arrays

let subjects = [
    "HTML",
    "CSS",
    "JavaScript"
];

console.log(subjects[0]);

10. DOM

DOM stands for Document Object Model. JavaScript can use the DOM to change HTML elements. 

document.getElementById("heading").innerHTML =
"Welcome Students";

11. Events

button.addEventListener("click", function() {

    alert("Button Clicked!");

});

12. Important Questions

Q1. What is JavaScript?

JavaScript is used to create interactive webpages.

Q2. What is DOM?

DOM represents the structure of an HTML document.

Q3. What is a function?

A function is a reusable block of code.
