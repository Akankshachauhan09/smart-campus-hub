Database Notes

Complete beginner-friendly Database study notes

1. What is a Database?

A database is an organized collection of data that can be easily stored, managed and accessed.

2. DBMS

DBMS stands for Database Management System.

It is software used to create, manage and access databases.

Examples:

  • MySQL
  • PostgreSQL
  • Oracle
  • MongoDB

3. SQL

SQL stands for Structured Query Language. It is used to work with relational databases. 

SELECT * FROM students;

4. Database Table

A table contains rows and columns.

  • Row = Record
  • Column = Field

5. SQL Commands

CREATE
INSERT
SELECT
UPDATE
DELETE

6. INSERT Data

INSERT INTO students
(name, course)
VALUES
('Student', 'Computer Science');

7. UPDATE Data

UPDATE students
SET course = 'BCA'
WHERE id = 1;

8. DELETE Data

DELETE FROM students
WHERE id = 1;

9. Primary Key

A primary key uniquely identifies each record in a table.

Example: Student ID

10. MongoDB

MongoDB is a NoSQL database that stores data in document-like structures.

MongoDB is commonly used with the MERN stack.
