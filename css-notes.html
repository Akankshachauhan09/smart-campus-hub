CSS Notes

Complete beginner-friendly CSS study notes

1. What is CSS?

CSS stands for Cascading Style Sheets. It is used to design and style HTML webpages.

CSS can change colors, fonts, spacing, sizes, layouts and make websites responsive.

2. CSS Syntax

selector {
    property: value;
}

Example:

p {
    color: blue;
    font-size: 18px;
}

3. CSS Selectors

  • Element Selector
  • Class Selector
  • ID Selector
  • Universal Selector
  • Group Selector
p {
    color: red;
}

.box {
    background: yellow;
}

#heading {
    color: green;
}

4. Colors

color: red;

color: #0d6efd;

color: rgb(0, 0, 255);

5. CSS Box Model

Every HTML element can be considered as a box. The box model contains:

  • Content
  • Padding
  • Border
  • Margin
.box {
    margin: 20px;
    padding: 15px;
    border: 2px solid black;
}

6. CSS Flexbox

Flexbox is used to create flexible layouts. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

7. CSS Grid

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

8. Responsive Design

Responsive design makes a website work properly on mobile, tablet and desktop devices. 

@media (max-width: 768px) {

    .container {
        width: 100%;
    }

}

9. Important CSS Properties

  • color
  • background
  • font-size
  • font-family
  • margin
  • padding
  • border
  • width
  • height
  • display
  • position

10. Important Questions

Q1. What is CSS?

CSS is used to style and design webpages.

Q2. What is a CSS selector?

A selector selects HTML elements that CSS rules should apply to.

Q3. What is Flexbox?

Flexbox is a CSS layout system used to arrange elements.
