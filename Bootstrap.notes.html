Bootstrap Notes

Complete beginner-friendly Bootstrap study notes

1. What is Bootstrap?

Bootstrap is a popular front-end framework used to create responsive and mobile-friendly websites quickly.

2. Bootstrap CDN

<link
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
rel="stylesheet">

3. Container

<div class="container">

    Content

</div>

4. Bootstrap Grid

Bootstrap uses a 12-column grid system. 

<div class="row">

    <div class="col-md-4">
        Column 1
    </div>

    <div class="col-md-4">
        Column 2
    </div>

    <div class="col-md-4">
        Column 3
    </div>

</div>

5. Buttons

<button class="btn btn-primary">
    Primary
</button>

<button class="btn btn-success">
    Success
</button>

<button class="btn btn-danger">
    Delete
</button>

6. Cards

<div class="card">

    <div class="card-body">
        Student Information
    </div>

</div>

7. Navbar

Bootstrap provides ready-made classes for creating navigation bars. 

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">

    <a class="navbar-brand" href="#">
        Smart Campus Hub
    </a>

</nav>

8. Bootstrap Utilities

  • m-3 → Margin
  • p-3 → Padding
  • text-center → Center text
  • text-primary → Primary text
  • bg-dark → Dark background
  • shadow → Shadow

9. Responsive Design

Bootstrap automatically provides responsive classes for different screen sizes. 

col-sm-12
col-md-6
col-lg-4

10. Important Questions

Q1. What is Bootstrap?

Bootstrap is a front-end CSS framework.

Q2. What is the Bootstrap grid?

It is a 12-column responsive layout system.

Q3. What is a container?

Container is used to hold and align webpage content.
